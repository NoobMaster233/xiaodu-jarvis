# 隐私与公开范围

## 公开的内容

公开仓库包含本项目的 Java/Python/JavaScript/脚本源码、中文说明、示例地址与提示词、自动检查、构建工具和许可。Release 包含从这些公开源码重新构建的两个 APK 与服务 JAR；第三方运行依赖由使用者按固定版本下载校验。

没有上传家庭 IP/MAC、Wi-Fi 密码、手机号、设备序列号、个人主对话 ID、登录态、浏览器数据、签名私钥、真实调试日志、个人录音、转写记录、二维码或媒体账号。没有包含原厂固件、设备分区镜像、校准数据或第三方商业应用安装包。原开发项目不会被整个推上 GitHub。

## 运行时声音往哪走

等待唤醒时，KWS 在设备上处理麦克风数据，不由本项目持续上传环境音。正式通话开启后，麦克风声音通过 WebRTC 交给 Codex 实时语音服务；这不是离线语音助手。Codex 账号对应的服务条款和数据政策仍适用。

桥接连接当前用户已经登录的 Codex，不读取或导出登录令牌，也不为局域网控制新增 token。设备原厂 DCS 仍保留已激活状态，用于加载与普通文字播报，本项目不是完整替换厂商系统，因此不能宣称设备上原有厂商网络行为都已审计或关闭。

普通 HTTP `say` 的文字会交给设备现有合成路径。实时通话音频不经这一条 TTS。截图、任务详情等接口可能返回私人内容，请只向可信 Agent 开放。

## 日志与配置

私有配置保留设备地址、主对话编号和状态目录；签名密钥只在构建者本机 `private/`。这些路径已经被 `.gitignore` 排除，发布脚本还使用独立允许清单，不能只依赖忽略文件。

里程碑记录只保存事件名、时间、状态和耗时，不保存音频/转写。任务管理器需要保存任务状态，可能含任务文字；Codex 自身也有对话记录。因此不要公开整个配置、state 或 Codex 目录。报告问题时优先提供错误类别、版本、时序和去标识的状态。

局域网控制服务没有鉴权，按用户自有可信网络设计。不要映射到公网，也不要给不可信网络中的任意 Agent 访问。
